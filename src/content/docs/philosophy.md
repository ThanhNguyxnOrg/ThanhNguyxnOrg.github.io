ThanhNguyxn's project workspace is built on one simple belief:

> real growth should be visible, organized, and honest.

## What that means

Not every project needs to look perfect. Some projects should simply be:

- experimental
- educational
- practical
- unfinished but valuable
- part of a longer journey

This workspace is not here to fake perfection. It is here to reflect **real learning** and **real building**.

## Core values

### 1. Learn deeply
I care about understanding systems, not just using them.

### 2. Build consistently
Even small progress matters.

### 3. Document clearly
Documentation is part of the project, not an extra.

### 4. Keep old work meaningful
Older code still tells part of the story.

### 5. Improve over time
Messy beginnings can still lead to strong outcomes.

## Final thought

This workspace is both:

- an archive of effort
- and a workshop for what comes next
