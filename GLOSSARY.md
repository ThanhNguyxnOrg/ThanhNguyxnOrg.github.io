# ThanhNguyxnOrg Site Glossary

Words this site uses with a fixed meaning. If copy on the page uses a term differently, the page is wrong, not this file.

## Language

**Org site**:
The GitHub Pages website at thanhnguyxnorg.github.io that supplements the `.github` profile repo.
_Avoid_: homepage, landing page, portfolio

**Profile repo**:
The `ThanhNguyxnOrg/.github` repository holding the org profile README and community files. The org site links to it, never duplicates it.
_Avoid_: main repo, docs repo

**Showcase**:
The Top 6 repositories by stars, synced from the profile README mechanism. The only ranked list on the site.
_Avoid_: featured, highlights, best projects

**Archive**:
The complete 16-repository list in alphabetical or neutral order. No ranking implied.
_Avoid_: all projects, full list

**Honest metrics**:
The four countable numbers: public repos, total stars, languages, npm packages. No views, no clones, no invented stats.
_Avoid_: hardcore stats, analytics, traction

**Baked data**:
Metrics fetched at build time by a scheduled workflow and committed as JSON. Visitors never touch the GitHub API quota.
_Avoid_: live fetch, realtime stats

**Snapshot**:
Baked data labeled with its fetch date. Staleness is stated, never hidden.
_Avoid_: cached, stale data

**Story**:
The one verified history sentence of a Showcase repo. Thin histories stay thin on the page.
_Avoid_: journey, saga, origin myth
